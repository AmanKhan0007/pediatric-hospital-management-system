# 🏥 KiddoCare — Pediatric Hospital Management System

KiddoCare is a modern, responsive Pediatric Hospital Management System designed to manage doctors, children (patients), appointments, prescriptions, and billing in a clean and interactive dashboard.

---

## ✨ Features

* 🔐 Role-based login (Admin, Doctor, Parent)
* 📅 Appointment booking system
* 👶 Child/patient management
* 🩺 Doctor management
* 💊 Digital prescriptions
* 🧾 Billing & invoice generation
* ⚡ Redis cache simulation
* 🎨 Beautiful animated UI
* 📱 Fully responsive design
